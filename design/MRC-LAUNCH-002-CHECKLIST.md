## The ⛔ GATES (go/no-go summary)

Commerce does **not** flip on until all of these are true:

- [ ] **G1 — The offer is true:** Pricing v2 deployed to prod; box page proves contents-at-retail > box price (savings ledger visible). *"Savings are proof of value" must be a fact, not copy.*
- [ ] **G2 — COGS gate:** supplier −10% negotiation closed **or** fallback applied (Complete at 349 per MRC-FIN-002). Complete GM ≥ 40%.
- [ ] **G3 — Money is legal:** VAT registration filed (voluntary, day-one) + Fatoora Phase-1-compliant invoices generated by the system.
- [ ] **G4 — Money is real:** production Tamara keys live; one real end-to-end SAR transaction succeeded and refunded on prod.
- [ ] **G5 — The box is real:** ≥1 box of each plan hand-packed, weighed, photographed; courier account open with a real quote per box.
- [ ] **G6 — The site is safe:** census hardening restored; both security criticals verified closed; two-pass e2e (`pnpm e2e`, commerce ON + OFF) green.
- [ ] **G7 — Someone is waiting:** ≥1,000 founding Cat IDs registered (or founder consciously waives the threshold and launches to the current count).

## PHASE C — Phase-0 marketing: the Census campaign (runs 6 weeks, start ASAP after A2)

*Authority: GTM-002. Target: 1,000 founding Cat IDs + ≥10,000 followers, ~zero paid. No prices, no countdowns, count UP only, Arabic leads, real named cats only.*

- [ ] Weekly: run every asset through the GTM-002 §30 QC checklist before it ships.

## PHASE F — First orders → first delivery

- [ ] **Order intake:** each paid order reviewed in admin same-day; confirm cat/plan/recipe/address; call or DM the member if the address is ambiguous (Riyadh addresses often are).
- [ ] **Pack** per D4 SOP with QA check; include the personalized insert (cat's name + member number — mono, of course).
- [ ] **First-box ceremony touch:** handwritten line on the card for the first ~20 members ("لولو، العضو رقم ٢١٧ — أول صندوق لك"). This is the delight budget; it costs a pen.
- [ ] **Ship within 48h of payment.** Enter tracking in admin; member gets the shipped notification.
- [ ] **Delivery day:** confirm receipt via courier POD; same-evening DM/WhatsApp: "did the box arrive well? how did [cat name] like it?" — every answer is logged.
- [ ] **The first delivery specifically:** be there if possible. Photograph/record (with consent) — the first real member unboxing is the most valuable marketing asset the company will own this year.
- [ ] **Feedback loop:** one-question NPS-ish ask after box 1 ("would you tell a friend with a cat?"), log every complaint verbatim, fix packaging/contents issues before the next pack run.
- [ ] **Reconcile:** every delivered order matched against payment + invoice + inventory decrement in the ledger (Qoyod/Wafeq). Inventory recount after the first 10 boxes.
